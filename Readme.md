# YouTube Trending Video Analytics

## 📌 Project Overview

This project analyzes YouTube trending videos to identify popular content, viewer engagement, trending duration, and differences between India and USA.

The analysis is performed using Python, Pandas, Matplotlib, Seaborn, and TextBlob.

## 🎯 Objectives

- Analyze YouTube trending videos.
- Identify popular videos and channels.
- Analyze views, likes, dislikes, and comments.
- Perform sentiment analysis on video titles.
- Analyze how long videos remain trending.
- Compare YouTube trending patterns between India and USA.
- Create visualizations to understand important trends.
